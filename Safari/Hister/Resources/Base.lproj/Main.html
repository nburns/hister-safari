Hister for Safari

Unofficial community port. Not affiliated with the upstream Hister project.

Enable the extension in Safari Settings, then click the toolbar icon to set your Hister server URL (default http://127.0.0.1:4433/).

The extension is on. Click the Hister toolbar icon to confirm the server URL, then browse as usual — visited pages are indexed automatically, same as the Chrome and Firefox extensions.

The extension is off. Turn it on in Safari Settings to start indexing pages you visit.

  1. Run a Hister server you control.
  2. Enable Hister in Safari → Settings → Extensions.
  3. Click the toolbar icon and save your server URL (and access token, if you use one).

Safari does not apply the Chrome/Firefox keyboard shortcuts automatically. Assign them under Safari → Settings → Extensions if you want the index / skip-rule commands.
